<!--d Updating HTMLy to the latest version d-->

The HTMLy update process is very safe. This is because the most important metadata such as username, category, type, tags, publication date, and slug is stored in the folder name and filename which is in the `content` folder. Any update-processes do not touch this folder, hence the safety of the process.

But if you like it better safe than sorry, then you can backup the `content` folder using `Backup` page and download it. 

Keep also in mind that if you change the specific Theme included in the package, without changing the Folder 'theme name', your changes will be lost, so download the theme and re-upload the theme. Read how to create a child theme so your modified theme gets not omitted: [Child Theme](https://docs.htmly.com/tips-trick/child-theme)

There are two ways to update HTMLy:

## Using the source code

1. Download the latest version from the [Github repo](https://github.com/danpros/htmly/releases/latest) (at the end of the page to those who are new to github)
2. Extract the zip file on your machine and replace the existing files in your webspace by ftp with the new extracted files.
3. Login and go to the admin area and clear the cache.
4. Done.

## Using the dashboard

1. Login to the admin area, visit `Check update` page (admin/update).
2. By visiting this page, if there is newer version, then there will be information about the latest version.
3. Scroll to the bottom and click the update button link.
4. Wait a moment, and after the update finished we will redirected to `Update to` page.
5. Clear the cache and you are done.
